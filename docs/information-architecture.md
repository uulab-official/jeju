# 소랑제주 정보 구조

## 제품 원칙

소랑제주는 여행지를 찾는 도구와 제주를 이해하는 문화 자료를 한 앱에 연결한다. 여행 전에는 발견과 저장, 여행 중에는 지도와 장소 상세, 여행 후에는 저장한 기록과 제주 문화 탐색이 자연스럽게 이어지도록 구성한다.

외부 서비스의 후기나 사진을 크롤링해 재게시하지 않는다. 후기는 앱 사용자가 직접 작성하고 수정·삭제·신고할 수 있는 백엔드와 운영 체계가 마련된 뒤 장소 상세의 하위 기능으로 제공한다.

## 1차 내비게이션

| 탭 | 사용자의 핵심 질문 | 주요 화면 |
| --- | --- | --- |
| 홈 | 지금 제주에서 무엇을 하면 좋을까? | 계절 추천, 액티비티 바로가기, 테마 여행 가이드, 여행지 큐레이션, 제주 역사·문화, 검색·알림 |
| 발견 | 내 취향에 맞는 장소와 체험은 어디일까? | 통합 검색, 액티비티 포함 카테고리 필터, 장소 목록, 장소 상세 |
| 지도 | 주변과 동선을 공간으로 보고 싶다 | 네이버 지도, 장소 마커, 장소 상세 |
| 저장 | 나중에 다시 볼 것은 무엇인가? | 저장한 여행지, 저장한 제주어 |
| 전체 | 제주 문화와 서비스 설정은 어디에 있나? | 제주 역사, 제주어 검색·표기법, 알림, 설정, FAQ, 약관, 개인정보, 앱 정보 |

## 2차 구조

```text
소랑제주
├─ 홈
│  ├─ 통합 여행지 검색
│  ├─ 알림 목록 → 알림 설정
│  ├─ 액티비티·걷기·섬·문화 바로가기 → 발견 필터
│  ├─ 테마 여행 가이드 → 순서별 추천 장소 → 장소 상세
│  ├─ 추천 장소 → 장소 상세 → 공식 출처·외부 지도·저장·공유
│  ├─ 제주 역사 → 시대별 이야기 → 공식 자료·관련 장소
│  └─ 제주 문화 → 자료 목록 → 자료 상세
├─ 발견
│  └─ 검색·필터 → 장소 상세
├─ 지도
│  └─ 마커 → 장소 상세
├─ 저장
│  ├─ 여행지 → 장소 상세
│  └─ 제주어 → 자료 상세
└─ 전체
   ├─ 제주 문화
   │  ├─ 제주 역사
   │  ├─ 제주어 통합 검색
   │  └─ 제주어 표기법
   ├─ 서비스
   │  ├─ 알림
   │  ├─ 설정 → 테마·알림
   │  └─ 자주 묻는 질문
   └─ 서비스 정보
      ├─ 개인정보 처리방침
      ├─ 이용약관
      └─ 앱 정보·데이터 출처·버전
```

## 이후 확장 순서

1. 비짓제주 등 허용된 공식 API를 통한 여행지 데이터 갱신과 출처·갱신일 표시
2. 일정 보관함: 테마 가이드와 저장한 장소를 날짜별 실제 동선으로 묶기
3. 1차 후기: 로그인, 작성·수정·삭제, 사진 권한, 신고·차단, 운영자 처리 체계를 갖춘 자체 콘텐츠
4. 개인화 추천: 명시적 동의와 데이터 삭제 경로를 갖춘 뒤 도입

후기와 일정은 실제 기능이 준비되기 전까지 스토어 설명과 스크린샷의 기능 주장에 포함하지 않는다.
